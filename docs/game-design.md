# ワードゴースト ゲーム設計ドキュメント

このドキュメントは、ワードゴーストというゲームの設計思想、ルール、設計判断の経緯、未解決事項を記録したものです。実装方針を判断する際の根拠となります。

---

## 1. ゲームの起点

ワードウルフをベースに以下の発明を加えたパーティーゲーム。

- **対となる言葉（対抗語）を誰も持っていないことがある**（あるいはそれがデフォルト）
- ゴール：**対抗語を当てること**

例：お題が「天使／悪魔」の語群でも、誰も悪魔を持っていない、ということが起こる。

## 2. 設計の出発点となった問い

ワードウルフは勝敗が明確に分かれる。それに対し、**全員が勝ち、全員が負ける**ような協力的勝敗構造の方が面白いのではないか、という発想。

## 3. 検討した方向性とその結論

### 案A：ハイブリッド型（採用）

ウルフ回とゴースト回が混在する。ウルフ回は通常のワードウルフのように少数派が紛れている。ゴースト回は全員が同じ語を持つ。

### 案B：常時ゴースト型（不採用）

全員が常に同じ語を持つ。検討の結果、**連想ゲームになりやすい**ため不採用。
- 「全員が同じ語を持ち、互いに知らない」設計を試したが、「色は？」のような直接質問でほぼ即解決してしまう
- 「歪み（属性／態度）」を加える案も検討したが、属性は質問でバレ、態度は演技力依存となり成立しない

### 勝利条件：「対抗語を当てる」（採用）

ワードウルフ準拠（ウルフを当てる／逃げ切る）ではなく、対抗語そのものを当てる方式を採用。

理由：ゴースト回において「**いつのまにか対抗語を集団で形にしていく**」という体験が、ゲーム名「ワードゴースト」と最も噛み合うため。ワードウルフ準拠だとゴースト回の判定が「悪魔の証明」になり成立しない。

### 勝利条件の対称／非対称：対称型を採用（条件付き）

選択肢として以下を比較：

1. **対称型**：全員でゴーストの語を当てる、勝敗共有
2. **非対称型**：人間は当てる／ウルフは当てさせない（撹乱役）
3. **議論誘導型**：勝敗を軽量化し議論を主役に

非対称型はインポスターゲーム的な疑心暗鬼が強くなり、ウルフの偽装負担も大きく、本ゲームの目指す「議論創造」と相性が悪いため不採用。

最終的に、**対称型をベースに駆け引きの匂いを残す折衷案**を採用。

## 4. 採用したルール

### 基本ルール

- プレイヤーは4〜6人を想定（後で詰める）
- 各プレイヤーにお題カードが配られる
- お題カードには**一つの語**のみが書かれている
- ウルフ回かゴースト回かはプレイヤーには明かされない

### 役職

- **人間**：多数派の語を持つ
- **ウルフ**：少数派の語を持つ（ウルフ回のみ存在）
- **ゴースト**：席にいない6人目（概念上）。ゴーストが持っている語が「対抗語」となる

### ゴーストという世界観 (γ)

ゴーストは「カード作成者の恣意」ではなく、**見えない他者**として位置づける。

- ウルフ回：ゴーストが人間プレイヤーに「憑依」している（ウルフ＝憑依された人）
- ゴースト回：ゴーストが空席にいる（誰も持っていない語を保持）

この世界観により、正解の恣意性問題が物語的に解消される（カード作成者と戦うのではなく、ゴーストと対話する構図になる）。

### 進行

1. カード配布（自分の語のみ見える）
2. 議論（自分の語について語り合う）
3. 全員で対抗語を一つ提出
4. ゴーストカードを開示し、一致すれば全員勝利

### 勝利条件

- **共通勝利条件**：全員でゴーストの語を当てれば全員勝ち
- **ウルフの個人ボーナス**：正体を最後まで隠せたら称号・拍手など（ゲーム全体の勝敗には影響しない）

### お題の禁止事項

- **自分の語を直接口に出してはいけない**（シミュレーション7のような即時崩壊を防ぐため）
- これは必須ルール

## 5. 設計の核（実装判断の指針）

### 議論創造を体験の中身、駆け引きを入口にする

参考：ボードゲーム『ito』の戦略。

- **販売・宣伝面**：「ウルフを暴け、ゴーストを見抜け」と駆け引きを匂わせる
- **実体験**：みんなで対抗語を作っていく対話ゲーム
- プレイヤーは駆け引きに惹かれて手に取り、議論創造の楽しさに気づいてリピートする

実装上の選択で迷ったら、**議論を促す方向**を選ぶ。駆け引きを盛り上げるためにルールを増やすのは原則NG。

### 勝敗の軽量化

- 点数システムは持たない（または軽い）
- 敗北時はゴーストカード開示と「敗因の言語化」時間を設ける（議論の続きとして楽しむ）

### お題カード設計の指針

- 対抗語は**一意に定まらない**ものを選ぶ（議論を促すため）
  - 良い例：海／猫／子ども／夏（複数の対抗語候補がある）
  - 悪い例：白／上（自明な対がある）
- ただし、カード作成者が想定する正解は一つに決める
- 議論で意外な対抗語が選ばれて外れた場合の「敗北の余韻」も体験価値の一部

## 6. 想定されるプレイ体験

### ウルフ回の例（お題「猫」、ゴーストの語「狼」）

- ウルフは「群れる」のような微妙にズレた発言をしてしまう
- 他プレイヤーは違和感から「ウルフがいる」と察する
- ウルフの発言を逆算して「群れる＋夜行性なら狼」と推理
- 全員「狼」で提出 → 正解

### ゴースト回の例（お題「子ども」、ゴーストの語「老人」）

- 全員の発言が噛み合うが、ウルフがいる可能性も否定できず疑心暗鬼が続く
- 「対抗語は大人か老人か」で議論が割れる
- 「人生の両端」という観点で老人に集約 → 正解

### 敗北パターン（お題「海」、ゴーストの語「空」）

- 「陸」「山」「空」で候補が割れる
- 議論で「空」も挙がるが、無難な「陸」で提出
- ゴーストカードは「空」→ 全員敗北
- 「空って言ってたのに採用しなかった」という余韻が残り、議論自体が記憶に残る

## 7. 未解決事項・議論の余地がある点

### A. 正解判定の細部

- カード作成者が想定する正解1つに対し、別の語で全員一致した場合をどう扱うか
  - 厳密にカード正解のみ → 恣意性が残る
  - 全員一致なら救済 → 緩すぎる可能性
- 現状の暫定方針：カード正解のみ。ただし運用で見直す

### B. ゴースト回の比率

- ウルフ回とゴースト回をどの比率で混ぜるか未確定
- 多すぎると毎回ゴースト回を疑い議論が単調化
- 少なすぎるとゴースト要素の意義が薄れる

### C. お題カードのプール

- 対抗語が一意に定まらないお題を選定する必要あり
- 文化依存（日本語話者前提か、汎用化するか）も未決定

### D. プレイヤー人数

- 4人〜6人を想定しているが、3人や7人以上での挙動は未検討
- 少人数だとウルフ回でウルフがバレやすい
- 多人数だと議論が散漫になる懸念

### E. 議論時間の制限

- タイマー制にするか、納得するまで議論できるか未決定
- パーティーゲームとしてはタイマー推奨だが、議論創造を主役にするなら緩めにすべき

### F. ウルフの個人ボーナスの具体化

- 「正体を隠せたら称号」とだけ決まっているが、具体的に何で動機づけするか未確定
- ゲーム後の投票で「ウルフは誰だった？」を当てる時間を設けるか

## 8. 参考にするゲーム

- **ワードウルフ**：ベースとなる構造、駆け引きの入口
- **ito**：協力ゲームの皮を被った議論ゲームという位置づけ
- **ディクシット**：勝敗を軽量化し議論を主役にする設計
- **コードネーム**：語の連想を集団で行う体験

## 9. 用語集

| 用語 | 意味 |

| お題 | 各プレイヤーに配られる語 |
| 対抗語 | お題の対になる語。ゲームで当てるべき答え |
| ゴースト | 対抗語を持つ概念上の6人目のプレイヤー |
| ウルフ | 少数派の語を持つプレイヤー（=ゴーストに憑依された人） |
| ウルフ回 | ウルフが存在する回 |
| ゴースト回 | 全員が同じ語を持ち、ウルフが存在しない回 |
| 憑依 | ウルフ回でゴーストが特定プレイヤーに重なっている状態 |
